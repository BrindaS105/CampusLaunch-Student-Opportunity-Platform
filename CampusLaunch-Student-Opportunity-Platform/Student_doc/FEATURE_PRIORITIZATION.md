
# Feature Prioritisation

## Method
Use a simple impact-versus-effort assessment for the first MVP.

| Feature | User Impact | Effort | Priority |
|---|---|---|---|
| Opportunity listing | High | Low | P0 |
| Search | High | Low | P0 |
| Category filtering | High | Low | P0 |
| Save opportunity | High | Low | P0 |
| Application tracking | High | Medium | P0 |
| Deadline reminders | Medium | Medium | P1 |
| Personalised recommendations | Medium | High | P2 |
| Employer portal | Medium | High | P2 |

## Prioritisation Rationale
The MVP focuses on discovery and organisation because these features directly address the initial problem while keeping implementation manageable.

## Future Reassessment
Priorities should be reviewed after user interviews and prototype testing.
