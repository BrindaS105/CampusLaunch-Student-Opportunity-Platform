
# Product Requirements Document (PRD)

## Product
CampusLaunch – Student Opportunity Discovery Platform

## 1. Problem
Students may discover internships, scholarships, and competitions through different sources. Managing saved opportunities and deadlines across multiple sources can be inconvenient.

## 2. Product Goal
Explore whether a unified opportunity dashboard can help students organise opportunities and track their application progress.

## 3. Target Audience
College students and recent graduates looking for early-career opportunities.

## 4. User Needs
- Find relevant opportunities.
- Search and filter listings.
- Save interesting opportunities.
- Track application progress.
- Remember deadlines.

## 5. MVP Scope
Must have:
- Opportunity listing
- Search
- Category filtering
- Save functionality
- Application status tracking

Could have:
- Deadline reminders
- Personalised recommendations

Not included in MVP:
- Real application submission
- Payment
- Employer verification
- User authentication

## 6. User Stories
As a student, I want to search opportunities so I can find relevant listings.

As a student, I want to save an opportunity so I can revisit it later.

As a student, I want to mark an opportunity as applied so I can track my progress.

## 7. Assumptions
- Students value having opportunities in one place.
- Basic search and status tracking are useful starting features.
- Users will need accurate and trustworthy listings.

These are product hypotheses, not validated research findings.

## 8. Risks
- Outdated opportunity information
- Unverified listings
- Low repeat usage
- Privacy concerns if personal data is collected

## 9. Success Criteria
Evaluate whether users can find, save, and track an opportunity without confusion. Define measurable targets only after collecting a baseline.
