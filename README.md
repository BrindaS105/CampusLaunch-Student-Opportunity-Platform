# CampusLaunch – Student Opportunity Discovery Platform

## Overview
CampusLaunch is a student-focused product prototype designed to make it easier to discover and organise internships, scholarships, and competitions.

## Problem Statement
Students may need to visit multiple websites to find opportunities and separately track deadlines and application progress. This can make opportunity management difficult.

This project explores a single, simple dashboard to organise that process.

## Target Users
- College students searching for internships
- Students looking for scholarships
- Students participating in competitions

## MVP Features
- Browse opportunity cards
- Search by title or organisation
- Filter by opportunity category
- Save opportunities
- Mark opportunities as applied
- View application counts
- Store saved and applied states in browser local storage

## Technology
- HTML
- CSS
- JavaScript
- Browser Local Storage

## Run Locally
1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Search and filter the demo opportunities.
4. Save an opportunity or mark it as applied.
5. Refresh the browser to test local storage.

No server or installation is required.

## Important Limitations
The opportunities are illustrative sample records. This prototype does not fetch live listings, verify organisations, or submit applications.

Saved data is stored only in the current browser.
